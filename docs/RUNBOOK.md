# 市政审理值班操作

交班时先打开占道许可台账，记下页尾运行指纹。需要调整处置量时，在工作台输入已确认的复核名额（单），查看变更后的占道许可台账，再从「许可附件」核对相关环节。

没有加载到样例时，先检查 `/health`。若健康接口已恢复，刷新页面并重新提交本班额度。输入超限会得到 `INVALID_SCENARIO`，页面保留上一次有效结果。

复核记录可通过工作台下载。导出包含前台展示的全部批次结果及七个环节的证据，便于按运行指纹对照。

开工前在「开工放行」入口核对放行与延期清单：普通工单复核未完成一律延期，逾期或缺件工单不得借放行绕过原结论；应急抢修条件放行的后续复核与补件凭据随清单一并签发。凭据库只增不减，落盘在 `var/clearance_journal.json`，同一批计划重跑不会重复出证，库内记录不可手工删改。
